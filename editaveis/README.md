# Personagens editáveis

Abra os arquivos no Blender 5.1. Cada arquivo contém a montagem principal do personagem, com malha simplificada, materiais e texturas empacotadas.

As cópias preservam uma cena de cada personagem e priorizam edição leve. As montagens históricas, os rigs separados e os arquivos de produção dos vídeos estão fora desta pasta. O cenário completo do tour está no código da galeria 3D.

Realização da Turma de Engenharia de Software da Faculdade de Nova Serrana (FANS). Consulte os [créditos e licenças](../site/creditos.html) para a atribuição dos materiais de terceiros usados na galeria.

## Personagens com rig

A pasta [com-rig/](com-rig/) reúne oito personagens com armadura, pesos, malha vinculada e texturas empacotadas. As ações de animação e as trilhas NLA foram retiradas. Abra no Blender e use o Modo Pose para ajustar a armadura.

Luiz Gama e Pixinguinha estão disponíveis como montagens editáveis. Os movimentos deles são definidos no código da galeria.
